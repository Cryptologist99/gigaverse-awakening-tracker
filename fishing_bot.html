Fishing Bot

An automated bot that plays Gigaverse's fishing minigame — built, tested, and maintained as its own open-source project.

The fishing bot lives in its own repository, not on this site. Head there for the code, setup instructions, and latest updates:

Cryptologist99/gigaverse-fishing-bot

Getting it running: the fastest way to set this up is to point your own coding LLM (Claude, ChatGPT, Cursor, etc.) at the repository and let it figure out the setup for your machine. Something like:

Clone https://github.com/Cryptologist99/gigaverse-fishing-bot, read the README, and get it running for me.

The repo's README and code comments have everything a coding assistant needs — dependencies, config, and how to start a run.

ℹ

The bot is probably not great at using oils. It knows how, but I've barely tested that path, so you'll need to set some parameters around how it uses them yourself. Same goes for rings.
